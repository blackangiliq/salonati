# صالوناتي · نموذج تفاعلي

نموذج كامل يشتغل بالمتصفح لتطبيق حجز الصالونات النسائية: الزبونة، صاحبة الصالون، والإدارة، مع استوديو لتجربة الستايلات.

**افتحيه من هنا:** https://blackangiliq.github.io/salonati/

## شلون تجربينه

- على الموبايل: افتحي الرابط، والتطبيق يملأ الشاشة. زر «الستايل» على حافة الشاشة يفتح الاستوديو.
- على الكمبيوتر: الموبايل بالنص، والاستوديو بالجانب.
- التسجيل يطلع بس وقت الحجز. الرمز التجريبي **2468**. زر «رقم تجريبي» يرجع زبونة عندها مواعيد، وأي رقم ثاني يبدي بـ 07 يسوي حساب جديد.
- بالاستوديو:
  - **الستايل**: ستايلات جاهزة، الألوان، فاتح وداكن، شكل الأيقونات، الخطوط، الزوايا، البطاقات، شريط التنقل، حجم الكتابة، والوضع المبسط. زر «نسخ الاختيارات» ينسخ اللي اخترتيه حتى ترسلينه.
  - **الشاشات**: بدّلي بين زبونة وصاحبة صالون والإدارة، وروحي لأي شاشة.
  - **الرحلة**: خطوات الحجز كاملة، آلة الوقت، انقطاع النت، فشل الدفع، وزبونة بدون حساب.

## ملاحظات

- الأسماء والأسعار والأرقام للعرض فقط. الخارطة رسم توضيحي، والرمز QR شكل بدون محتوى.
- الفيديوهات والصور من [Mixkit](https://mixkit.co/) بترخيص مجاني.
- كل جهاز يحفظ تجربته لوحده بالمتصفح. زر «ابدي العرض من جديد» بتبويب الرحلة يرجع كل شي مثل أول مرة.

## التشغيل على الجهاز

افتحي `index.html` مباشرة بالمتصفح. الخطوط تحتاج نت.
